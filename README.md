# Илья — 10 лет

Статический сайт-подарок с десятью отдельными страницами для видео.

## Как добавить видео

Положите MP4-файлы в папку `dist/videos` с такими именами:

```text
video-01.mp4
video-02.mp4
video-03.mp4
video-04.mp4
video-05.mp4
video-06.mp4
video-07.mp4
video-08.mp4
video-09.mp4
video-10.mp4
```

Любое видео можно заменить через режим редактирования. Там же можно загрузить фотографию для обложки карточки на главной странице. После настройки Yandex Object Storage видео, фотографии, заголовки и подписи синхронизируются между устройствами.

## Временная загрузка в Yandex Object Storage

Сгенерируйте ограниченные подписанные формы. Скрипт спросит ключи интерактивно и не сохранит секретный ключ:

```bash
python3 scripts/generate-upload-config.py
```

Результат записывается в `dist/upload-config.js`. В нём нет секретного ключа: только временные разрешения для заранее заданных объектов.

Для лучшей совместимости используйте MP4 с кодеками H.264 + AAC.

## Проверка локально

Из папки проекта запустите:

```bash
python3 -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`.

## GitHub Pages

Workflow уже находится в `.github/workflows/deploy-pages.yml`. Создайте репозиторий, загрузите проект, затем в настройках GitHub откройте **Settings → Pages → Source** и выберите **GitHub Actions**. Каждый push в ветку `main` будет публиковать содержимое `dist`.
